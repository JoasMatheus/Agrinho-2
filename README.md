# 🌱 Agro Forte, Futuro Sustentável

Projeto de página inicial inspirado na estética acolhedora e pixelada de Stardew Valley, com foco no tema:

> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.”**

O site apresenta uma proposta visual temática voltada ao agronegócio sustentável, utilizando elementos retrô, cores naturais e uma experiência amigável para destacar práticas agrícolas conscientes e tecnologias sustentáveis.

---

# 📸 Prévia do Projeto

## ✨ Destaques

- 🎮 Visual inspirado em Stardew Valley
- 🌾 Tema agrícola sustentável
- 💧 Seção sobre preservação ambiental
- 🚜 Cards com soluções ecológicas
- 📊 Área de impacto sustentável
- 🖼️ Galeria temática
- 📱 Layout responsivo
- 🎨 Estilo pixel art retrô

---

# 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando apenas tecnologias front-end:

- **HTML5**
- **CSS3**
- **Google Fonts**
- Design responsivo com Flexbox e Grid
